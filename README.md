# Личный кабинет ВЭШ — интерактивная презентация

Сайт для отдела продаж и административного отдела. [Открыть презентацию](https://veshk.github.io/lk-presentation/). [Рабочий ЛК](https://student.veshk.ru/login).

Срез содержания: **26 ноября 2026 года**. В презентации используются десять настоящих снимков рабочего сайта. Упрощённые макеты первой версии удалены. Будущая аналитика отдельно обозначена как пример с условными числами.

## Что можно посмотреть

- Общий просмотр обучения сотрудником: три вида обучения и карточка курса в записи.
- Учебная группа: первый экран, расписание, записи по модулям, материалы и вопросы.
- Курс в записи: обложка, урок с программой слева, анкета обратной связи.
- Бесплатный Power Query: административный предпросмотр черновика.
- Пояснения по пронумерованным меткам, увеличение исходного снимка, переключение экранов.
- Три схемы доступа, работа двух отделов и пример будущего отчёта.
- Режим показа, навигация между восемью главами и возврат к началу просмотра.

## Что именно изображено

Страницы сняты на student.veshk.ru после входа сотрудника. Общий просмотр имеет заголовок «Все группы и курсы»; его нельзя выдавать за персональную главную слушателя. У слушателя — «Моё обучение» и собственные назначения. Это различие явно поясняется рядом со снимком.

Страницы группы и платного курса сняты в режиме просмотра сотрудника. Служебная полоса, кнопки редактирования/возврата и сообщения о предпросмотре не являются интерфейсом обычного слушателя. Бесплатный курс на дату съёмки находится в черновике; показ интерфейса не означает, что курс опубликован или кому-либо выдан. В его снимок не включена верхняя полоса аккаунта.

Изображения не перерисованы. Метки, переключатели и увеличение — элементы презентации поверх снимков. Внутри фотографий кнопки не работают. Реальные ответы, личные данные и доступы слушателей не опубликованы.

Исходные снимки находятся в `assets/screens/`; подписи, координаты меток и пояснения — в `screens.mjs`. При обновлении сначала снять и проверить новый экран, затем заменить изображение и связанные пояснения.

## Запуск и проверка

Сборка и установка зависимостей не нужны. Из этого каталога:

```sh
python3 -m http.server 8097 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8097/ . ES-модули требуют HTTP, поэтому `file://` не подходит.

```sh
node --check app.mjs
node --check model.mjs
node --check screens.mjs
```

Проверять переключение снимков и пояснений, увеличение, закрытие по кнопке и Escape, возврат фокуса, навигацию по главам, схемы доступа, роли, учебную аналитику. Для адаптации использовать ширины 1280, 390 и 320 px. В увеличении на телефоне предусмотрена внутренняя прокрутка изображения. Выбранные кнопки обозначены `aria-pressed`, пояснения доступны с клавиатуры; уменьшение движения поддерживается.

## Данные и ограничения

Состояние существует только в памяти страницы. Нет API, хранилища, регистрации, платежей, отправки сообщений, аналитических трекеров или соединения с рабочей базой. Презентация не изменяет рабочий ЛК.

Учебная воронка: бесплатные `[100,70,42,25]`, платные `[40,36,26,20]`. Все — сумма зачислений, не уникальных людей. Этапы вложенные, проценты от открытых доступов. Окно — первые 30 дней после открытия доступа для условной когорты 1–7 октября. Первая отметка урока не равна просмотру видео. Пример 8 покупок из 100 человек за 60 дней — отдельная иллюстрация будущего анализа, не вычисление из воронки.

Логотип, Inter и фоновое изображение — ресурсы существующего публичного предпросмотра ЛК. Лицензия Inter приложена. Снимки — рабочий сайт от 26.11.2026. Оформление продолжает стиль самого ЛК.

## Публикация и откат

Публикуется корень отдельного репозитория `Veshk/lk-presentation`, ветка `main`, GitHub Pages из `/`. После коммита проверить GitHub Pages и соответствие публичных файлов локальным. Для отката восстановить файлы репозитория из предыдущего коммита; другие пути не затрагивать.
