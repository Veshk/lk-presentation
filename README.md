# Личный кабинет ВЭШ — глазами слушателя

[Открыть презентацию](https://veshk.github.io/lk-presentation/). Аудитория: отдел продаж и административный отдел ВЭШ. Срез: 26.11.2026.

## Примеры

В презентации семь примеров с областями интерфейса слушателя:

- Вход с почтой и паролем, регистрация и восстановление пароля.
- Страница группы: обложка, ближайшее занятие и меню разделов.
- Расписание.
- Записи занятий по модулям.
- Материалы и вопросы об обучении.
- Обложка курса в записи.
- Программа и видео урока.

Примеры используют настоящие снимки student.veshk.ru, без перерисовки. Вход снят с публичной страницы. Остальные исходные снимки получены ранее в разрешённом просмотре сотрудника, а в презентации показаны только общие для слушателя области. Для этого используется точное кадрирование; оно одинаково в галерее, обложке и увеличении. Персональная главная и личный срок конкретного слушателя не имитируются.

Общий каталог сотрудника, бесплатный черновик и анкета в отключённом предпросмотре убраны из примеров. Служебные полосы и административные варианты статусов за пределами кадра. Снимки являются фрагментами страниц, а не полной копией текущей сессии слушателя. О будущем развитии аналитики рассказывается без имитации отчёта и условных показателей.

Метки раскрывают пояснения. «Рассмотреть экран» увеличивает тот же фрагмент. Кнопки внутри изображения не совершают действий в ЛК. Переключатели схем доступа и ролей сотрудников объясняют работу команды, не изображая административный интерфейс.

## Устройство

- `index.html`: восемь глав, навигация и окно увеличения.
- `screens.mjs`: снимки, точные границы кадра, метки и пояснения.
- `app.mjs`: переключение примеров, увеличение и режим показа.
- `style.css`: оформление и адаптация.
- `assets/screens/`: исходные снимки; кадрирование задаётся в данных и CSS.

Состояние хранится только в памяти страницы. API, отправки форм, платежей, трекеров и подключения к данным слушателей нет. Изображения не содержат личных данных слушателей. Логотип, фон и Inter — ресурсы ЛК; лицензия Inter приложена.

## Запуск и проверка

Из этого каталога:

```sh
python3 -m http.server 8097 --bind 127.0.0.1
node --check app.mjs
node --check screens.mjs
```

Открыть http://127.0.0.1:8097/ . Для модулей нужен HTTP, открытие через file:// не поддерживается.

Проверять все семь примеров и границы кадра, переключение пояснений, увеличение, закрытие кнопкой и Escape, возврат фокуса, навигацию по главам. На телефоне увеличенный снимок прокручивается внутри окна. Основная страница должна помещаться в ширину. Проверенные размеры: 1280×720, 390×844, 320×760.
